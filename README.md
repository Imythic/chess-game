# chess-game

**Play it live:** https://imythic.github.io/chess-game/ — a browser port (HTML/CSS/JS) of the game below, same rules and AI, no install needed.

A fully playable chess GUI built from scratch in Python/Tkinter — legal move validation, castling, pawn promotion, and an optional AI opponent you can toggle per side. The `docs/` folder contains the browser port; `chess.py` is the original desktop version.
